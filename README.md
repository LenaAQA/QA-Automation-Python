<h2>👨‍💻 Обо мне:</h2>



<p align="justify">Я инженер по тестированию ПО (Fullstack QA) сс опытом ручного и автоматизированного
тестирования веб-приложений, REST API и корпоративных SAP-систем. <br> 
Опыт включает функциональное, регрессионное, интеграционное и E2E тестирование пользовательских
интерфейсов и REST API. Занималась анализом требований, подготовкой тестовой
документации, выявлением и сопровождением дефектов, а также автоматизацией UI- и API-
тестирования.<br>
  <br>
Пишу автотесты на Python с использованием Pytest, Selenium, HTTPX, Requests, Pydantic, Faker
и Allure. Также использовала TypeScript (Playwright) и Go (Testify) для автоматизации
тестирования.<br>
  <br>
Есть опыт:<br>
• разработки тест-кейсов, чек-листов и E2E-сценариев с применением техник тест-дизайна;<br>
• тестирования frontend, backend и REST API;<br>
• функционального и E2E тестирования мобильной версии веб-приложений на Android;<br>
• проверки бизнес-логики, валидаций, интеграций, HTTP-статусов, структуры и содержимого
ответов API;<br>
• работы с Git/GitHub, CI/CD, Allure, DevTools, Postman, Swagger, SQL и Linux;<br>
• разработки и поддержки архитектуры UI- и API-автотестов с использованием Page Object
Model, API clients, models/schemas, fixtures и кастомных assertions;<br>
• сопровождения и тестирования внутренних корпоративных систем SAP: проведение
функционального тестирования, ретеста, анализ дефектов, подготовка тестовой документации
и взаимодействие с техническими специалистами при устранении проблем.<br>
  <br>
В рамках проектов:<br>
• разработано ≈ 100 UI и ≈ 85 API тест-кейсов, ≈ 20 чек-листов;<br>
• реализовано ≈ 45 UI-автотестов и ≈ 50 API-автотестов;<br>
• выявлено и оформлено ≈ 50 дефектов и более 200 инцидентов/отчетов в рамках
сопровождения и тестирования корпоративных систем;<br>
• подготовлена Postman-коллекция из 50 API-запросов с автопроверками на JavaScript;<br>
  <br>
Готова осваивать новые инструменты и технологии и при необходимости адаптироваться к
стеку проекта. Нацелена на долгосрочное сотрудничество.<br>
</p>
