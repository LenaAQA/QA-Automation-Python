<h2>👨‍💻 Обо мне:</h2>



<p align="justify">Я инженер по тестированию ПО (Fullstack QA) с опытом ручного и автоматизированного тестирования веб- и API-сервисов. Пишу автотесты на Python (Pytest, Selenium, HTTPX, Requests), также использовала TypeScript и Go.<br> 
  
Прошла обучение в компании Авито по программе "QA Engineer: ручное и автоматизированное тестирование", где отработала полный цикл тестирования: анализ требований, подготовка тестовой документации (тест-кейсы, чек-листы, E2E-сценарии), проведение ручного тестирования, оформление дефектов и последующая автоматизация UI и API тестов. <br>
  
Обучалась автоматизации тестирования на Python в RedRover.School, где работала с Selenium, Pytest, Allure и шаблоном Page Object Model (POM). Получила практический опыт написания тест-кейсов, создания автотестов, их рефакторинга и генерации отчётности в Allure. <br>

Есть опыт тестирования REST API: проверка статус-кодов, заголовков, структуры и содержимого ответов, негативных сценариев, граничных значений и некорректных входных данных. Разработала фреймворк API-автотестов с использованием HTTPX, Pydantic, Faker, Pytest и Allure, интегрировала автотесты в CI/CD. <br>

Также окончила курс Артёма Русова «Тестирование ПО с нуля. Теория + Практика», где изучила основы тестирования и освоила работу с инструментами DevTools, JIRA, Confluence, Test IT, Postman, SOAPUI, Charles Proxy, MySQL, Android Studio, Git, Bash. <br>
  
В рамках проектов: <br>
- разработано ≈ 75 UI и ≈ 85 API тест-кейсов, ≈ 15 чек-листов; <br>
- реализовано ≈ 45 UI-автотестов и ≈ 50 API-автотестов; <br>
- подготовлена Postman-коллекция из 50 запросов с автопроверками на JavaScript; <br>
- выявлено и оформлено ≈ 50 дефектов. <br>

Опыт работы оператором ЭВМ более 10 лет: занималась регистрацией и анализом дефектов программного обеспечения и оборудования, взаимодействовала с техническими специалистами при их устранении (оформлено более 200 отчетов). <br>
Также участвовала в тестировании системы SAP для учёта рабочего времени: разработка чек-листов, анализ функциональности, выявление дефектов и предоставление обратной связи разработчикам. <br>

Готова осваивать новые инструменты и технологии и при необходимости адаптироваться к используемому в проекте стеку. Нацелена на долгосрочное сотрудничество.  <br>
Буду рада рассказать о себе подробнее на собеседовании. <br> 
</p>
